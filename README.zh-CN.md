# Resume as Code (简历即代码)

[English](README.md) | 简体中文

本项目实现了“简历即代码”的理念，利用大语言模型 (LLM) 和结构化数据自动化创建高度定制、专业的简历。

它解决了简历维护中的常见痛点：

- **碎片化**：为不同的职位申请维护多个 Word/PDF 文件版本。
- **不一致**：难以在不同版本之间保持格式和内容的一致性。
- **耗时**：为每个职位描述 (JD) 手动定制简历既单调又乏味。

通过维护一份职业生涯的“主时间轴”并使用 AI 智能体动态组装简历，你可以在几分钟内为任何工作机会生成完美的匹配。

## ✨ 核心特性

- **单一事实来源**：所有职业数据（工作、项目、教育、证书）都存储在模块化的 YAML 文件中。
- **AI 驱动的智能体**：
  - **简历生成智能体**：分析 JD 并组装目标简历。
  - **时间轴润色智能体**：使用 STAR/3W 方法论润色原始经历描述。
  - **面试准备智能体**：基于你的简历和目标 JD 生成全面的面试指南。
- **标准化格式**：基于 [YAMLResume](https://yamlresume.dev/docs) 标准，确保与丰富的各个主题和导出工具生态系统兼容。
- **自动化校验**：集成校验确保生成的简历语法正确并准备好编译。
- **多格式导出**：支持通过 YAMLResume 编译器导出为 PDF (LaTeX)、HTML 和 Markdown。
- **多语言支持**：自动从职位描述或用户输入中检测目标语言。支持生成英文、简体中文、繁体中文 (港/台)、西班牙文、法文和挪威文。

## 🏗️ 架构与工作流

系统通过三个主要的 AI 智能体运行：

### 1. 时间轴润色智能体

_输入：职位或项目的原始文本描述。_
_输出：存储在 `timelines/gem/` 中的结构化、润色的 YAML 文件。_

1.  **输入分析**：识别输入是工作经历还是项目。
2.  **润色**：对工作经历应用 **STAR** (情境、任务、行动、结果)，对项目应用 **3W** (是什么、为什么、怎么做)。
3.  **强化**：推断相关的技术关键词和行业背景。
4.  **存储**：将润色后的产出保存到时间轴库中。

### 2. 简历生成智能体

_输入：目标职位描述 (JD)。_
_输出：存储在 `resumes/gem/` 中的完整、定制的简历 YAML 文件。_

1.  **职位分析**：从 JD 中提取关键技能、要求和角色背景。
2.  **匹配**：基于分析结果从时间轴库中选择最相关的经历。
3.  **片段生成**：生成定制的总结、技能、工作和项目章节。
4.  **组装**：将所有章节与静态个人信息（教育、证书）组合成最终符合 YAMLResume 标准的文件。
5.  **校验**：针对模式校验输出结果。

### 3. 面试准备智能体

_输入：简历、JD 分析、公司业务分析。_
_输出：存储在 `interviews/gem/` 中的全面面试准备指南。_

1.  **输入验证**：确保所有必要的背景文件都存在。
2.  **策略生成**：创建针对该角色的个人介绍策略。
3.  **深度钻研**：为每个项目生成基于 STAR 的深度挖掘问题。
4.  **问答库**：创建一个涵盖特定技术、架构和领域知识的广泛技术问答库。
5.  **行为与反向面试**：准备行为面试问题和高质量的反向面试问题。

```text

├── profiles/           # 个人基础信息（静态）

│   ├── temp/           # 中间生成产出

│   └── interview-prompt.md # 面试指南生成提示词
```

## 🤖 AI 工具支持与配置

本项目利用 AI 智能体自动化简历生成过程。虽然它可以与各种 LLM 配合使用，但已针对以下工具进行了优化：

### 1. GitHub Copilot

- **状态**：支持 (推荐)
- **配置**：无需特定配置。你可以直接在 VS Code 中与 Copilot Chat 交互。

### 2. Trae

- **状态**：支持
- **配置**：
  1.  **创建智能体**：在 Trae 中创建一个新的自定义智能体 (Custom Agent)。
  2.  **配置规则**：复制 [.trae/rules/project_rules.md](.trae/rules/project_rules.md) 的内容并将其粘贴到智能体的指令中。
  3.  **保存**：将智能体命名为 **`resume-as-code`**。
- **用法**：在处理此项目时选择 **`resume-as-code`** 智能体，以确保严格遵守工作流。

## 🚀 使用指南

### 前提条件

- 已安装 **Node.js** 和 **pnpm**。
- 已安装 **YAMLResume CLI**。本项目依赖 `yamlresume` 来编译和构建各种格式（PDF、HTML、Markdown）的简历。
  - 请参考官方 [安装指南](https://yamlresume.dev/docs/installation) 进行设置。
- 一个 LLM 接口（例如 VS Code 中的 GitHub Copilot Chat）。

### 第 1 步：构建你的时间轴库

先不要写简历。首先，构建你的经历数据库。

1.  打开 Copilot Chat。
2.  粘贴过去工作或项目的原始描述。
3.  **时间轴润色智能体** 将其格式化为 `timelines/gem/` 中的结构化 YAML 文件。
4.  检查并保存文件。

### 第 2 步：配置静态数据

在 `profiles/` 目录中填写你的静态信息：

- `profiles/basics.yml`：联系信息、社交链接。
- `profiles/education.yml`：教育历史。
- `profiles/certificates.yml`：证书。

### 第 3 步：生成简历

当你找到想要申请的工作时：

1.  复制职位描述 (JD)。
2.  将其粘贴到 Copilot Chat 中。
3.  **简历生成智能体** 将：
    - 分析 JD。
    - 选择相关的时间轴事件。
    - 生成定制内容。
    - 在 `resumes/gem/` 中组装最终的 YAML 文件（例如 `姓名_职位_公司.yml`）。

### 第 4 步：编译与导出

使用 YAMLResume CLI 编译你的简历为 PDF 或 HTML。

```bash
pnpm yamlresume build "resumes/gem/Your_Resume.yml"
```

### 第 5 步：准备面试

一旦你的简历准备就绪：

1.  将生成的 **简历**、**JD 分析** 和 **公司业务分析** 提供给 Copilot Chat。
2.  **面试准备智能体** 将在 `interviews/gem/` 中生成详细指南。
3.  使用此指南练习你的自我介绍、项目深挖和技术问答。
